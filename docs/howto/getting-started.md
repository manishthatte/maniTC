# HOW-TO: Getting started

This guide walks you through building the maniT toolchain from source, writing
your first program, and running it on both backends.

---

## Prerequisites

- Rust 1.70+ with Cargo (`rustup` recommended)
- Optional: `clang` for LLVM/x86-64 compilation

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source ~/.cargo/env
```

---

## 1. Clone and build

```bash
git clone <repo_url> maniT
cd maniT
cargo build
```

The workspace builds two binaries:

| Binary | Location | Purpose |
|--------|----------|---------|
| `manitc` | `target/debug/manitc` | Compiler |
| `trit` | `target/debug/trit` | Build tool |

Add them to your PATH for convenience:

```bash
export PATH="$PATH:$(pwd)/target/debug"
```

---

## 2. Hello, world

Create `hello.mt`:

```maniT
use std::io;

fn main() {
    io::println("Hello from maniT!");
}
```

### Compile and run on T3ISA (balanced ternary emulator)

```bash
manitc compile --target t3 hello.mt
manitc run-t3 a.t3b
```

Expected output:

```
[T3ISA] running a.t3b (... words)
Hello from maniT!

```

### Compile to LLVM IR (x86-64)

```bash
manitc compile --target llvm hello.mt
```

If `clang` is available:

```bash
./a.out
```

Otherwise, manually compile the `.ll` file:

```bash
clang a.ll -o hello
./hello
```

## 3. Using the build tool

Create a new project:

```bash
trit new myproject
cd myproject
```

This creates:

```
myproject/
├── trit.toml          # project metadata
└── src/
    └── main.mt        # entry point template
```

Build and run:

```bash
trit run                   # compile (LLVM) + run
trit run --target t3       # compile (T3ISA) + run in emulator
```

Other commands:

```bash
trit build                 # compile only
trit check                 # type-check only (no code generation)
trit test                  # compile and run files in tests/
trit fmt                   # format all .mt files in src/
trit doc                   # generate docs/index.md from doc comments
trit clean                 # remove build/ directory
```

## 4. Project structure

A typical maniT project:

```
myproject/
├── trit.toml
├── src/
│   ├── main.mt        # must contain fn main()
│   ├── utils.mt       # helper module
│   └── types.mt       # shared types
├── tests/
│   ├── test_utils.mt
│   └── test_types.mt
└── docs/
    └── index.md       # generated by trit doc
```

### trit.toml

```toml
[package]
name = "myproject"
version = "0.1.0"
```

## 5. Trit literals and ternary types

```maniT
use std::io;

fn main() {
    // trit literals: +, 0, -
    let a: trit = +;
    let b: trit = -;

    // three-way branch
    tif a {
        + => io::println("positive"),
        0 => io::println("zero"),
        - => io::println("negative"),
    }

    // bool3 (three-valued boolean)
    let sensor: bool3 = unknown;
    tif sensor {
        + => io::println("sensor OK"),
        0 => io::println("sensor reading uncertain"),
        - => io::println("sensor fault"),
    }

    // balanced ternary literal
    let n = 0t+0-;    // = 8
    io::print_int(n);
    io::newline();
}
```

## 6. Structs and methods

```maniT
use std::io;
use std::fmt;
use std::math;

struct Point {
    pub x: float,
    pub y: float,
}

impl Point {
    fn new(x: float, y: float) -> Point {
        Point { x: x, y: y }
    }

    fn distance(self) -> float {
        math::sqrt(self.x * self.x + self.y * self.y)
    }

    fn to_str(self) -> str {
        fmt::format("({}, {})", self.x, self.y)
    }
}

fn main() {
    let p = Point::new(3.0, 4.0);
    io::print("Point: ");
    io::println(p.to_str());
    io::print("Distance from origin: ");
    io::print_float(p.distance());
    io::newline();
}
```

## 7. Enums and pattern matching

```maniT
use std::io;

enum Color {
    Red,
    Green,
    Blue,
    Custom(int, int, int),
}

fn color_name(c: Color) -> str {
    match c {
        Color::Red   => "red",
        Color::Green => "green",
        Color::Blue  => "blue",
        Color::Custom(r, g, b) => "custom",
    }
}

fn main() {
    let c1 = Color::Red;
    let c2 = Color::Custom(128, 64, 255);

    io::println(color_name(c1));
    io::println(color_name(c2));
}
```

## 8. Result type and error handling

```maniT
use std::io;

fn divide(a: int, b: int) -> Result<int, str> {
    if b == 0 {
        Err("division by zero")
    } else {
        Ok(a / b)
    }
}

fn main() {
    match divide(10, 2) {
        Ok(v) => {
            io::print("10 / 2 = ");
            io::print_int(v);
            io::newline();
        }
        Err(e) => io::println(e),
        Unknown(msg) => io::println(msg),
    }

    match divide(10, 0) {
        Ok(v) => io::print_int(v),
        Err(e) => io::println(e),     // prints "division by zero"
        Unknown(msg) => io::println(msg),
    }
}
```

## 9. Debug utilities

Inspect intermediate compilation stages:

```bash
# Print the token stream
manitc lex hello.mt

# Print the AST
manitc parse hello.mt

# Type-check and print stats (no code generation)
manitc check hello.mt

# Compile with IR dump
manitc compile --target t3 --emit-ir hello.mt
```

---

## 10. Format source code

```bash
# Format a single file
trit fmt                   # formats all files in src/

# Or via the build tool in your project
cd myproject && trit fmt
```

The formatter:
- Normalises indentation to 4 spaces
- Adds spaces around binary operators
- Removes trailing whitespace
- Ensures a blank line between top-level items

## 11. Generate documentation

Add doc comments with `///` above functions and types:

```maniT
/// Computes the nth Fibonacci number iteratively.
/// Returns Ok(result) or Unknown("overflow") if n is too large.
fn fib(n: int) -> Result<int, str> {
    ...
}
```

Generate documentation:

```bash
trit doc
```

Output is written to `docs/index.md`. It contains a Markdown page with sections
for each type (functions, structs, enums, traits) with their signatures and doc
comment bodies.
