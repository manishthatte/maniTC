# Code of Conduct

## The short version

Be decent to people. Argue with ideas, not with the person holding them.

This project exists to put a new kind of computing in everyone's hands. That
purpose is poorly served by a hostile room.

## Expected behaviour

- Assume the other person is acting in good faith and is competent.
- Criticise designs, code and claims freely and directly — that is the work.
- Accept the same in return.
- Take correction gracefully. Being wrong in public is how a language gets
  better.
- Newcomers asking obvious questions are the point, not an interruption.

## Unacceptable behaviour

- Personal attacks, harassment, or sustained hostility.
- Demeaning remarks about anyone's background, nationality, gender, religion,
  disability, or level of experience.
- Publishing others' private information.
- Deliberately derailing discussions or wasting maintainers' time in bad
  faith.

## Scope

This applies in the issue tracker, discussions, pull requests, commit
messages, and any other space where you are participating in the project.

## Enforcement

Report problems to **manish@manitlab.org**. Reports are read by the project
steward, Manish Jagdish Thatte, and kept confidential.

Responses, depending on severity: a private word, a public correction, a
temporary block, or a permanent ban from the project's spaces. The steward
decides. Contributions already merged are not reverted for conduct reasons —
the code stands on its own.

## A note on scale

This is currently a one-person project with a young community. There is no
committee behind this document, and none is being implied. It exists so that
expectations are written down before they are needed.
